# POS Local MX 1.1.6 — Drive final release

- POS: `com.koreanmarket.localpos`, versionCode **10**.
- Embedded updater: **1.1.1**, versionCode **3**.
- Distribution: approved Google Drive folder; signed metadata: `latest-drive.json` and `.sig`.
- The earlier 1.1.6 / code 8 APK is preserved. Code 10 upgrades safely after bridge code 9;
  do not distribute the old code 8 APK as the final step.

For POS 1.1.5, use the existing update button to install GitHub bridge **1.1.5.1**, then reopen POS.
Approve its embedded-helper installation and continue to the offered Drive **1.1.6** update.
Keep `latest.json` on the bridge so older GitHub-only downloaders can reach it.

Only this final APK includes the explicitly approved **2,557-product** snapshot. Names, prices,
costs and stock can be extracted by anyone with the link. Original Excel files, device databases,
sales, backups and upload credentials are not included. POS creates a verified internal backup
before one-time catalog application. Existing sales, payments and returns remain; numeric stock
is replaced by the approved snapshot and unknown stock remains unchanged.

The helper verifies the signed manifest, APK hash, byte size, package, signing certificate and
version. HTML/login/error downloads fail closed. Android still requires installation approval.
**Back up outside the device and install over the existing app; never uninstall or clear data.**
Physical-device installation, reopening and data-preservation tests have not been performed.

## 한국어

최종 버전은 **1.1.6 / 내부 코드 10**, 도우미는 **1.1.1 / 코드 3**입니다.
이전 1.1.6 코드 8 파일은 보존하지만 브리지 코드 9 다음에 설치할 최종 파일은 코드 10입니다.

1.1.5에서 업데이트 버튼으로 GitHub의 1.1.5.1을 설치한 뒤 POS를 다시 열면,
내장 도우미 설치 확인과 Drive 최종 업데이트를 이어갈 수 있습니다. 별도 도우미 파일 탐색은 필요 없습니다.
Android의 설치 허용 및 확인은 사용자가 승인해야 합니다.

승인된 상품 2,557개는 최종 APK에만 포함됩니다. 적용 전 내부 백업, 한 번만 적용하는 처리,
판매·결제·반품 기록 보존을 유지합니다. 숫자로 명시된 재고는 최신 자료로 덮어씁니다.
상품정보를 APK에서 추출할 수 있으나 기기의 매출·백업이나 업로드 인증정보는 포함하지 않습니다.
실물 Android 기기의 설치·재실행·데이터 보존 시험은 미실시이므로 현장 확인이 필요합니다.
