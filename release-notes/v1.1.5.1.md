# POS Local MX 1.1.5.1 — compatibility bridge

- POS: `com.koreanmarket.localpos`, versionCode **9**.
- Embedded updater: **1.1.1**, versionCode **3**, with the existing signing certificate.
- Distribution: this GitHub Release. Legacy `latest.json` remains pinned to this bridge.
- No store catalog, database, sales, backup or private signing key is bundled.

From POS 1.1.5, press the update button and install this bridge over the existing app.
Reopen POS and approve installation of its embedded updater, then continue to the offered
**1.1.6 / code 10** update from Google Drive. No separate helper APK search is needed.
Android installation permissions and confirmation remain necessary; installation is not silent.

Create an off-device backup first. **Do not uninstall POS or clear its app data.**
Physical Android device installation, reopen flow and data-preservation tests have not been performed.

Drive 1.1.6 업데이트** 순서입니다. 도우미 파일을 따로 찾을 필요는 없지만 Android 설치 확인은 눌러야 합니다.
