PRIVACIDAD

Los datos de la tienda se quedan en la tienda.

Última actualización: 20 de octubre de 2026.

POS Local MX

  • No requiere cuenta, inicio de sesión ni servidor.
  • No incluye anuncios, analítica, telemetría ni seguimiento comercial.
  • Productos, ventas, inventario, ajustes y configuración se guardan localmente en Android.
  • La cámara se usa únicamente para leer códigos de barras cuando el usuario abre el escáner.
  • El usuario controla la importación, exportación y copia de respaldo mediante el selector de archivos de Android.

Actualizaciones

El actualizador es una aplicación separada. Comprueba la versión publicada en GitHub una vez al día y también cuando el usuario lo solicita manualmente. Solo descarga el APK cuando existe una versión nueva y el usuario inicia la descarga; Android vuelve a pedir confirmación antes de instalarlo. El catálogo, las ventas, el inventario, los respaldos y la configuración de la tienda no se incluyen en esas solicitudes. El puente 1.1.5.1 se descarga de GitHub, incluye el nuevo actualizador y no contiene catálogo. La versión final 1.1.6 se descarga de Google Drive. Como en cualquier conexión HTTPS, Google y GitHub pueden recibir la dirección IP y los datos técnicos normales de la solicitud conforme a sus propias políticas.

Con autorización del propietario, el APK 1.1.6 contiene una copia de 2,557 productos (nombres, precios, costos y existencias). Cualquier persona con el enlace puede extraerla. Esto no envía datos desde el dispositivo: el catálogo autorizado viaja dentro del APK. Las ventas, los respaldos y las credenciales no están incluidos.

Control de los datos

La desinstalación de POS Local elimina sus datos locales de acuerdo con el comportamiento de Android. Antes de desinstalar o cambiar de dispositivo, el usuario debe crear y conservar un respaldo en una ubicación propia.

한국어 개인정보 안내

로컬 POS는 계정, 광고, 분석 SDK와 원격 서버를 사용하지 않습니다. 상품, 판매, 재고와 설정은 Android 기기 내부에 저장됩니다. 카메라는 사용자가 스캐너를 열었을 때 바코드 인식에만 사용합니다.

별도 업데이트 도우미는 하루 한 번 또는 사용자가 수동으로 요청할 때 GitHub의 공개 서명 버전 정보를 확인합니다. 새 버전 APK는 사용자가 다운로드를 누른 경우에만 받고, 설치 전에는 Android가 다시 확인을 요청합니다. 매장의 상품 목록, 판매 기록, 재고, 백업과 설정은 업데이트 요청에 포함되지 않습니다. 브리지 1.1.5.1은 GitHub에서 받으며 새 도우미를 내장하고 상품정보는 포함하지 않습니다. 최종 1.1.6 APK는 Google Drive에서 받습니다. 일반적인 HTTPS 접속과 마찬가지로 Google과 GitHub에는 IP 주소와 기본 접속 기술 정보가 전달될 수 있으며, 각 서비스의 정책에 따라 처리됩니다.

소유자의 승인으로 1.1.6 APK에 상품 2,557개의 이름·가격·원가·재고가 포함되어 있으며, 링크를 가진 사람은 이를 추출할 수 있습니다. 이는 승인된 상품 스냅샷을 APK와 함께 배포하는 것으로, 기기의 판매 기록·백업을 업로드하지 않습니다. 인증정보도 포함하지 않습니다.
