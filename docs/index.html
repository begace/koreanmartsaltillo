ACTUALIZACIÓN DESDE 1.1.5

Actualiza desde el botón del POS

  1. Instala 1.1.5.1En POS 1.1.5, pulsa actualizar e instala el puente desde GitHub.
  2. Abre de nuevoSigue el aviso del POS y confirma la instalación del actualizador 1.1.1 que ya viene incluido.
  3. Instala 1.1.6Continúa con el aviso de actualización para descargar la versión final desde Drive.

Conserva siempre un respaldo fuera del teléfono. Para actualizar, instala el APK nuevo sobre la versión existente; no desinstales la app, porque Android eliminaría sus datos locales.

No necesitas buscar ni descargar un APK del actualizador por separado. Android sí pide autorizar y confirmar las instalaciones; no se instalan en silencio. Si cancelas, puedes continuar desde Configuración → Actualización de la app.

El puente 1.1.5.1 no incluye catálogo. Solo la versión final 1.1.6 (código 10) aplica los 2,557 productos autorizados una vez, con respaldo previo. Actualiza precios y existencias numéricas y conserva ventas, pagos y devoluciones. No borres los datos de la app.

La instalación, reapertura y conservación de datos aún no se han probado en un dispositivo Android físico; requieren verificación en el equipo de la tienda.

업데이트할 때 기존 앱을 삭제하지 말고 새 APK를 그대로 설치하세요. 앱을 삭제하면 기기에 저장된 로컬 데이터도 삭제됩니다.

기존 POS 업데이트 버튼 → GitHub 1.1.5.1 설치 → POS 다시 열기 → 내장 도우미 1.1.1 설치 확인 → Drive 1.1.6 업데이트 순서입니다. 도우미 APK를 따로 찾아 다운로드할 필요가 없습니다. Android의 설치 허용·확인은 직접 눌러야 합니다. 취소했다면 설정 → 앱 업데이트에서 이어갈 수 있습니다.

1.1.5.1에는 상품정보가 없습니다. 최종 1.1.6은 내부 버전 코드 10이며, 이전에 게시한 코드 8 파일은 보존합니다. 실물 Android 기기의 설치·재실행·데이터 보존 시험은 아직 수행하지 않았으므로 매장 기기에서 확인이 필요합니다.

브리지 APK는 GitHub, 최종 APK는 Google Drive, 서명된 버전 정보는 GitHub Pages에서 내려받습니다. 최종 APK에 포함된 상품명·가격·원가·재고는 링크를 가진 사람이 추출할 수 있습니다. 기기의 판매 기록이나 백업을 외부로 전송하는 기능은 없습니다.
